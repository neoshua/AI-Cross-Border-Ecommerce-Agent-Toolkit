# platform-title-rules.md · 标题规则卡（TikTok Shop 泰国站）

> 阈值来自 TikTok Shop 官方 Seller Center / Academy 的商品标题质量规则（2026-10 口径），
> **发布前到卖家中心复核**——平台会调整，且类目间有差异。

---

## 一、硬性规格

| 规则 | 内容 | 级别 |
|---|---|---|
| 字符长度 | **25 – 255 字符**（双向卡口：太短判信息不足，太长被截断） | 硬 |
| 语言 | **泰语为主**（品牌名、型号、通用缩写可用英文） | 硬 |
| 字符集 | 标准字母与数字；禁止非常规 ASCII（Æ / Š / Œ / Ÿ / Ž 之类） | 硬 |
| 数字 | 用阿拉伯数字（`2` 不是 `two` / `สอง` 拼写） | 软 |
| 计量单位 | 用缩写（`cm` / `kg` / `ml` / `นิ้ว`），全篇统一 | 软 |
| 品牌 | 未获授权不得写品牌名，无品牌填「无品牌」；写了品牌名必须有授权链 | 硬 |
| 二手商品 | **泰国站强制**：标题必须以 `[Second-hand]` 开头 | 硬 |

---

## 二、标题必须包含的信息（官方要求）

按顺序给足信息，缺哪项补哪项 —— 不是堆词，是补信息：

1. **品牌名**（已获授权时）
2. **商品类型**（买家搜索用的核心品类词，放最前）
3. **材质或主要成分**（如适用）
4. **核心特征**（颜色 / 功能 / 规格）
5. **数量或容量**（净重 / 容积 / 包装数量）

> 同一商品页卖多规格（100ml / 150ml / 200ml）→ 标题列全规格，或用变体承载并在标题点名范围。

---

## 三、硬禁项（命中即不合格）

| 项 | 说明 |
|---|---|
| 促销信息 | `ส่งฟรี` / `ลดราคา` / `โปรโมชั่น` / `ของแถม` / free shipping / sale —— 促销是主图与活动位的活，不是标题的 |
| 变体与库存表述 | `มี 5 สี` / `8 sizes available` / `in stock` / `เหลือ 3 ชิ้น` —— 规格差异放变体，库存状态买家自己能看 |
| 同一词语重复 ≥ 4 次 | 注意是 **4 次**（不是 Shopee 时代的 3 次），重复成分/香型/节日词同样算 |
| 标题党式表达 | `ขายดีที่สุด` / `ถูกที่สุด` / `อันดับ 1` / best seller / No.1 —— 无凭证的绝对化宣称 |
| 表情与特殊符号 | emoji、装饰性符号一律清掉 |
| 平台/渠道标记 | 不得出现 TikTok、其他平台名、官网、联系方式 |
| 中文 | 买家可见文本出现中文 = 直接错（内部备注不算） |

## 四、泰语写法要点（决定 CTR，不是合规项）

- **主关键词前置**：移动端首屏只显示约 40 字符，核心品类词必须落在这一段。
- **短语之间留空格**：泰语不分词，但标题里用空格分隔短语（`กระเป๋าเป้ กันน้ำ ขนาด 20 นิ้ว`）比一整串更易扫读，也便于平台分词匹配。
- **避免中文词序直译**：`กันน้ำกระเป๋าเป้`（防水背包）与 `กระเป๋าเป้กันน้ำ`（背包·防水）是不同语感，后者才是买家写法。修饰语在后。
- **量词跟着名词**：`กระดาษ 2 ม้วน`（2 卷纸），量词不能省。
- **品牌名保持原拼写**，不要音译成泰文——搜索匹配靠原词。

## 五、校验实现说明（title_lint.py）

```bash
python scripts/title_lint.py "标题文本" --platform tiktok_th
python scripts/title_lint.py 标题清单.txt --platform tiktok_th --keywords กระเป๋า,กันน้ำ
```

- **字符数 = `len()`**，不是字节数。泰文字符在 UTF-8 里占 3 字节 —— 按字节算会把一条 90 字的合规标题误判成 270 超限。这正是「实测 vs 估算」的差异来源。
- **重复词检测分两路**：有空格 → 按空格分词统计；无空格 → 12/10/8/6 字滑窗兜底，取最长命中并合并重叠片段。
- 禁用词匹配**大小写不敏感**，按整词结果输出（不会把 iPhone 拆成单字母）。
- 促销词表分两级：促销/免运/折扣 = FAIL；畅销/绝对化宣称 = WARN（官方列为质量问题，非直接拒审）。
- 语言检查：出现中文 = FAIL；整条无泰文 = WARN（纯英文标题在泰国站拿不到自然流量）。
- 自备禁用词清单（竞品品牌、类目敏感词）用 `--forbidden` 或 `--forbidden-file` 追加。
