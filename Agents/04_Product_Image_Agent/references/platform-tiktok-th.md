# TikTok Shop 泰国站 · 商品图规则卡

> 来源：TikTok Shop 官方《商品发布指南（东南亚）》+ Seller Center 图片规范 + 2026 卖家实践。
> **发布前到卖家中心复核**，平台会调整审核口径。

---

## 一、硬性规格

| 项 | 要求 |
|---|---|
| 数量 | 每个商品最多 **9 张**（首图 + 8 张附加） |
| 比例 | **1:1 正方形**（首图与附加图都按 1:1 准备，非正方会被裁切） |
| 尺寸 | 官方下限 **600×600**（大量类目审核按 800×800 起）；**推荐 1000×1000 – 1200×1200** |
| 格式 | JPG / JPEG / PNG |
| 单图大小 | **≤ 5 MB** |
| 色彩空间 | sRGB |
| 视频 | 每个商品最多 **1 条**，≤ 100 MB，缩略图 **1080×1920（9:16）** |

---

## 二、首图（主图）红线

| 项 | 要求 | 级别 |
|---|---|---|
| 背景 | **纯色，白色最优**（纯白之外的干净纯色可接受，但白底搜索表现更稳） | 硬 |
| 商品占比 | 官方 ≥ **60%**；实战甜区 **80–90%** | 硬 |
| 完整性 | 完整正面视图，不得裁掉商品一部分 | 硬 |
| 文字 | ❌ 首图禁文字、贴纸、促销角标、价格标 | 硬 |
| 水印 / Logo | ❌ 禁水印、第三方 Logo、边框 | 硬（自动审核直接拒） |
| 道具 / 人手 | ❌ 首图不放道具、人手、模特（穿戴类例外） | 软 |
| 拼图 | ❌ 一张图只放一个商品，多规格用变体区分 | 硬 |
| 一致性 | 图中颜色/款式必须与所售 SKU 一致，否则判图文不符 | 硬 |
| 清晰度 | 禁模糊、过曝、拉伸变形、重滤镜；过度修图会被标记 | 硬 |

> 泰国站特别提示：工业秤、厨房秤等计量类商品需上传**资质/标签图**（厨房秤须有明显
> 「Do not use the scale for trading」标签），否则审核不过 —— 这类图占一个附加图位。

---

## 三、附加图位（2–9 图）该放什么

| 图位 | 内容 | 文字 |
|---|---|---|
| 1 首图 | 纯色底正面图，商品占 80–90% | ❌ 无文字 |
| 2 | 侧面 / 背面 / 45° 角度 | 可少量 |
| 3 | 材质、工艺、细节特写 | 可标卖点 |
| 4 | 真实使用场景（可有人物、模特） | 可 |
| 5 | **尺寸对照**（手/硬币/标注长宽高） | ✅ 标数字 |
| 6 | 卖点信息图（2–3 个核心卖点） | ✅ 字号保证手机可读 |
| 7 | 变体 / 颜色选项一览 | ✅ |
| 8 | **包装清单**（含什么、不含什么） | ✅ 明确标注「ไม่รวม」 |
| 9 | 信任状（认证、质保、检测报告） | 可 |

- 附加图允许实景背景、允许文字叠加，但**不得遮挡商品主体**，也不要把附加图做成像横幅广告。
- ❌ 美妆 / 健康 / 保健品禁止「使用前后对比图」（before-after），改拍质地、成分、使用过程。
- ❌ 图内不得出现未经证实的功效宣称（`cures` / `clinically proven` / `FDA approved` 之类），会触发人工复核。

## 四、AI 生成图的边界

平台允许 AI 生成素材，但要求**内容真实、不误导**：

- 生成的商品外观必须与真实商品一致（颜色、尺寸、材质、结构、配件数量）。
- 不得用 AI 虚构功能、扩大容量、虚构认证或赠品。
- 不得抹掉真实瑕疵后当作实物图（详情页展示的应是买家会收到的那个东西）。
- 建议：AI 只用于背景替换、场景合成、信息图排版；商品本体用实拍抠图。

## 五、像素校验参数（对应 scripts/check_main_image.py）

```bash
python scripts/check_main_image.py 图.png --platform tiktok_th
python scripts/check_main_image.py 图.png --platform tiktok_th --fix 修复后.png
```

| 检查 | 阈值 | 依据 |
|---|---|---|
| 最小尺寸 | ≥ 600px，**<1000px 警告** | 官方下限 / 推荐值 |
| 正方形 | 宽高比 1:1（±1%） | 非正方形被自动裁切 |
| 主体占比 | ≥ 60% fail；**甜区 80–95%** | 官方下限 + 实战 |
| 背景 | 纯白优先（软提示）；纯色也可，但背景必须干净 | 官方「纯色，推荐白色」 |
| 文件大小 | ≤ 5 MB | 官方上限 |
| 首图文字/水印/Logo/边框 | **人工确认**（脚本不测 OCR） | 自动审核重点拒因 |

## 六、最常见的 5 个驳回原因（按频次）

1. 首图带文字或促销角标 → 去掉，挪到附加图。
2. 商品占比太小（<60%）→ 重新框选，留 5–10% 边距即可。
3. 图片小于 800×800 → 导出 1200×1200 再传，别用放大插值糊上去。
4. 白底不白（灰底、米底、带阴影）→ 用 `--fix` 拉白，或重拍。
5. 图文不符（图是红色，SKU 是蓝色）→ 每个变体配自己的图。
