# 视频平台规范卡（TikTok Shop 泰国站）

> ⚠️ 以下为编写时的公开规则整理（2026-10）。平台规则会更新，
> **发布前必须到卖家中心与创作者中心复核原文**。

## 一、商品卡视频（Listing 里的那条）

| 项 | 要求 |
|---|---|
| 数量 | 每个商品最多 **1 条** |
| 文件 | **≤ 100 MB**，MP4（H.264） |
| 时长 | 建议 **15–30s**（允许更长，但前 3 秒决定是否被划走） |
| 画幅 | **9:16 竖版 1080×1920**（商品卡与 Feed 共用同一套构图） |
| 首帧 | **必须即产品**——不要台标、不要空镜、不要 logo 动画 |
| 字幕 | **必须烧录泰语**（大量用户静音刷），单行 ≤ **30 字符** |
| 音频 | 泰语口播优先；纯 BGM 版本要保证字幕能独立读懂 |
| 缩略图 | 1080×1920（9:16），主体居中，避开底部 20% |

## 二、带货短视频 / 直播切片（内容场）

| 项 | 要求 |
|---|---|
| 画幅 | 9:16，1080×1920 |
| 时长 | 15s（首屏拦截）/ 30s（完整卖点链）两个版本各做一条 |
| 安全区 | **底部 20%**（文案、购物车、评论区入口）+ **右侧 15%**（点赞/评论/分享按钮）不放关键信息 |
| 前 3 秒 | 钩子：痛点疑问 或 结果前置，二选一，不堆两个 |
| 语音 | 泰语口播；语速约 **12 字符/秒**（`video_timing.py` 默认值） |
| 字幕 | 泰语，单行 ≤ 30 字符，两行封顶，字号 ≥ 画面高度 4% |

---

## 三、通用红线（与 Listing 同一套合规守卫）

- **不夸大**：不写「最好 / 第一 / 100% 有效」，无凭证的绝对化表述会被限流。
- **不假演示**：演示的功能必须真实存在（不做加速、不换产品、不摆拍效果）。
- **不前后对比**：美妆 / 健康 / 保健类禁止 before-after 画面。
- **不用未授权音乐**：走平台商用曲库；热点音乐要看是否标注可商用。
- **不带其他平台水印**：带 Shopee / Lazada / 其他平台 logo 或水印的视频会被压流量。
- **AI 素材要真实**：AI 生成的画面不得改变商品外观、容量、配件数量；不得冒充实拍。
- **参数必须溯源**：口播与字幕里出现的每个数字，都要能对上 `spec_table`
  （用 03 的 `spec_consistency.py` 复核）。

---

## 四、黄金 3 秒（0–3s 钩子）

- 第一句台词 **≤ 3 秒**（按 12 字符/秒 ≈ 36 个泰文字符内）
- 画面必须有动作（开机 / 倒水 / 拉伸 / 计时器跳动），不要静态产品照
- 钩子之后立刻给「一个」卖点，不要连抛三个——观众只记得住一个

---

## 五、时长与字幕校验

```bash
python scripts/video_timing.py --script 配音稿.txt --target tiktok30
python scripts/video_timing.py --script 配音稿.txt --target 15 --cps 12 --subtitle-max 30
```

- 泰语**不分词**，脚本按**字符数**估算时长（默认 12 字符/秒），不再按英文词数。
- 混排（泰语 + 英文型号）时，两段分别计时后相加。
- 字幕行长按字符数卡 30 —— 超了就拆句，不要靠缩字号。
