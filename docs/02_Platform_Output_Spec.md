# 02 · 平台输出字段规范（TikTok Shop 泰国站）

> ⚠️ **所有指标以卖家中心 / 创作者中心实时规则为准。** 本表为编写时（2026-10）的公开规则整理，
> 平台会调整，**发布前请复核一次**。硬指标写错比不写更危险。

---

## 一、标题（Product Name）

| 项 | 要求 |
|---|---|
| 字符长度 | **25 – 255 字符**（双向卡口） |
| 语言 | **泰语为主**；品牌名、型号、通用缩写保留英文 |
| 结构公式 | 核心品类词 +（品牌，需授权）+ 材质/成分 + 核心特性（功能/规格/颜色）+ 数量或容量 |
| 数字 | 阿拉伯数字；单位用缩写（`cm` / `kg` / `ml` / `นิ้ว`） |
| 二手商品 | **必须以 `[Second-hand]` 开头**（泰国站强制） |

### 硬禁项

- 促销信息：`ส่งฟรี` / `ลดราคา` / `โปรโมชั่น` / `ของแถม` / sale / free shipping
- 变体与库存表述：`มี 5 สี` / `8 sizes available` / `in stock` / `เหลือ 3 ชิ้น`
- 同一词语重复 **≥4 次**（成分、香型、节日词同样算）
- 标题党式表达：`ขายดีที่สุด` / `ถูกที่สุด` / `อันดับ 1` / best seller
- 表情符号、装饰性特殊字符、非常规 ASCII
- 中文（买家可见文本出现中文 = 直接错）
- 平台名 / 其他渠道名 / 联系方式

### 泰国站写法要点

- **主关键词前置**：移动端首屏只显示约 40 字符，品类词必须在这一段。
- **短语之间留空格**：`กระเป๋าเป้ กันน้ำ ขนาด 20 นิ้ว` 比一整串更易扫读，也更利于平台分词。
- **修饰语在后**：`กระเป๋าเป้กันน้ำ`（背包·防水）而不是中文词序直译的 `กันน้ำกระเป๋าเป้`。
- **量词不能省**：`กระดาษ 2 ม้วน`。
- 完整规则卡 → [`Agents/03_Listing_Creative_Agent/references/platform-title-rules.md`](../Agents/03_Listing_Creative_Agent/references/platform-title-rules.md)

## 二、图片

| 项 | 要求 |
|---|---|
| 数量 | 最多 **9 张**（首图 + 8 附加） |
| 比例 | **1:1** |
| 尺寸 | 官方下限 **600×600**；推荐 **1000×1000 – 1200×1200** |
| 格式 / 大小 | JPG / JPEG / PNG，**≤ 5 MB** |
| 首图背景 | **纯色，白色最优**（纯色可接受，白底搜索表现更稳） |
| 首图主体占比 | 官方 ≥ **60%**；实战甜区 **80–90%** |
| 首图文字 | ❌ 禁文字、贴纸、促销角标 |
| 水印 / Logo / 边框 | ❌ 禁（自动审核直接拒） |
| 图文一致 | 图中颜色/款式必须与所售 SKU 一致 |

### 首图与附加图的分工

首图只负责「一眼看清是什么」；**卖点文字、尺寸标注、包装清单全部放第 2–9 图**。
这与「首图叠大字报提升点击」的老习惯相反 —— TikTok 的自动审核会把首图文字判违规。

### 泰国站特有必备图

- 工业秤、厨房秤等计量类商品：需上传资质文件图 / 标签图（厨房秤须有明显
  「Do not use the scale for trading」标签）。
- 部分类目需认证图（TISI / NBTC 等），缺图审核不过。

完整规则卡 → [`Agents/04_Product_Image_Agent/references/platform-tiktok-th.md`](../Agents/04_Product_Image_Agent/references/platform-tiktok-th.md)

## 三、详情页 / 描述

### 推荐结构（7 段）

| # | 段落 | 内容要点 | 风险提示 |
|---|---|---|---|
| 1 | 一句话定位 | 这是什么、给谁用 | 与标题核心词一致 |
| 2 | 核心卖点 | 最多 3 个，每个可验证 | 禁绝对化表述 |
| 3 | 使用场景 | 让买家代入 | 场景必须是产品真实能覆盖的 |
| 4 | 详细参数 | 尺寸/材质/容量/重量/包装 | 不得虚标，数字溯源 `spec_table` |
| 5 | 尺寸表 / 对照 | 长宽高 + 参照物 | 服装鞋包必备 |
| 6 | 包装清单 | 含什么、**不含什么**（`ไม่รวม`） | 差评主要来源，必须写 |
| 7 | 注意事项与售后 | 使用限制、保修、退换 | 承诺要有能力兑现 |

- 描述里可以放图（图文混排优于纯文字）。
- 泰国买家习惯先看「尺寸」和「包装清单」两段，别把这两段埋在最后。

## 四、视频

| 项 | 要求 |
|---|---|
| 数量 | 每个商品 **1 条** |
| 文件 | **≤ 100 MB**，MP4（H.264） |
| 画幅 | **9:16 竖版 1080×1920** |
| 时长 | 建议 15–30s；前 3 秒定生死 |
| 字幕 | **烧录泰语**，单行 ≤ 30 字符 |
| 安全区 | 底部 20%（购物车/文案）、右侧 15%（互动按钮）不放关键信息 |
| 缩略图 | 1080×1920，主体居中 |

## 五、规格属性（Product Attributes）

1. **能填就填满**：完整度高的 listing 搜索与推荐权重更优。
2. **不确定就留空，不要编**：编参数 = 差评 + 退货 + 罚分。
3. **品牌字段**：有授权选品牌并上传授权链；无品牌填「无品牌」，不要在标题里蹭品牌词。
4. **重量尺寸如实填**：直接决定物流计费与体积重（长×宽×高÷8000，单边 <1000cm，体积重 ≤100kg）。
5. **类目别选错**：类目错放会导致下架或被限流，发布前再核一次。

## 六、费率与定价口径（THB）

| 成本项 | 参考值 | 说明 |
|---|---|---|
| 平台佣金 | **8.56%**（普通店主流类目）/ 9.63%（Mall）/ 7.22%（电子） | 按（商品税前价 − 卖家优惠）计 |
| 商业增长费 | **8.03%**（电子 6.96%） | 不计入佣金，独立扣 |
| 交易手续费 | **3.21%** | 计费基数含平台发给买家的券 |
| 按笔固定费 | **THB 1.07 / 笔** | 低价商品占比高，先算账 |
| 目标毛利率 · 大件 | 30–35% | 前期可略低养权重 |
| 目标毛利率 · 小件 | 25–30% | 同上 |
| 广告成本 | 5–10% | 计入定价 |
| 退货损耗 | 2%（电子 3%） | 计入定价 |
| VAT | **7%** | 定价模型默认 0，**必须自行补** |
| 头程 + 尾程 + 仓储 | 按实际 | 全塞进 `--cost` 一个参数，别重复计 |

> 完整核算模型见 [`Templates/cost_pricing_template.md`](../Templates/cost_pricing_template.md)，
> 费率预设见 [`Agents/02_Product_Strategy_Agent/scripts/platform_fees.json`](../Agents/02_Product_Strategy_Agent/scripts/platform_fees.json)。

## 七、上架前检查表（TikTok 泰国站）

| 检查项 | 为什么 |
|---|---|
| 标题 25–255 字符且无促销词 | 太短/太长/带促销都会被判质量问题 |
| 标题有泰文字符 | 纯英文标题拿不到自然流量 |
| 二手商品有 `[Second-hand]` 前缀 | 泰国站强制，缺了会被驳回 |
| 首图 1:1、≥1000px、纯色底、无文字 | 首图是驳回率最高的一项 |
| 9 图用满且含尺寸图 + 包装清单 | 差评两大来源就在这里 |
| 视频 9:16、泰语字幕、底部留空 | 竖版才进 Feed，字幕避开 UI |
| 品牌授权链已上传（如填了品牌） | 无授权填品牌 = 山寨判定 |
| 类目 / 必备资质图 | 计量类、电子类有强制图 |
| 参数全部能对上 `spec_table` | 参数虚标 = 后续纠纷 + 罚分 |
